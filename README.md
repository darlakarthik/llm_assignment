# Colombia IMF Report Analysis

This project analyses Colombia’s 2023 IMF Article IV Consultation report using Python. It extracts PDF text, generates summaries, collects financial indicators and creates a four-panel dashboard.

## Files needed

Download the notebook and `columbia_2023.pdf` from this repository.

The source is **IMF Country Report No. 23/120**, containing 80 pages.

## How to run

1. Open the notebook in Google Colab.
2. Select **Runtime → Change runtime type → T4 GPU**.
3. Upload `columbia_2023.pdf` to the Colab working folder.
4. Run all 16 code cells in order.

Keep the PDF filename unchanged. The first run downloads the models and takes longer. Cached results are reused while the local cache remains
